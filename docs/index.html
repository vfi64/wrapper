Stable DOI policy

Use concept DOIs in handbook/README/website. Version DOIs are release-specific and should be used only for pinned reproducibility.

  • Runtime concept DOI: 10.5281/zenodo.18445672
  • Ruleset concept DOI: 10.5281/zenodo.17928357

Installation tracks

Separate onboarding for non-technical users and professional users.

  • Beginner path: bash scripts/setup_venv.sh
  • Advanced path: explicit Python + tests + diagnostics
  • Details: HANDBOOK.md / HANDBOOK.de.md

API key onboarding

Create provider keys only in official portals and always check billing before productive usage.

  • Gemini: API key / pricing
  • OpenRouter: API keys / models + pricing
  • Hugging Face: tokens / pricing

Security guidance

Never commit secrets. Prefer environment variables in shared or production-like setups.

  • Local key file: Config/Comm-SCI-API-Keys.json (gitignored)
  • Template: Config/Comm-SCI-API-Keys.example.json
  • Current encrypted key support is documented in the handbook.
Recommended start: open German handbook (or English handbook), follow the installation path for your target audience, then configure provider keys securely.
