# Why the Wrapper Exists

## Starting Point

A ruleset describes target behavior, but it does not enforce stable execution by itself.

In normal chat environments, compliance with detailed governance can drift with model, context, and session length.

## Purpose

The wrapper exists because a ruleset without technical execution can remain a wish.

It adds an operational layer for:

- deterministic command handling,
- explicit runtime contracts,
- repeatable state transitions,
- auditable output and diagnostics.

## What It Is Not

The wrapper is not a truth machine and not an autonomy booster.

Its purpose is control: visible, reproducible, inspectable answer behavior.

## Relation to Comm-SCI-Control

- Comm-SCI-Control: normative governance definition.
- Wrapper runtime: operational enforcement and observability.
